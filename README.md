# Revia

システム音声はAPIキーなしで利用できます。「設定」→「音声設定」で声を選べます。

ElevenLabsの音声を利用する場合は、[**ElevenLabs API Key**](https://elevenlabs.io/docs/overview/administration/workspaces/api-keys) を設定してください。

1. [**ElevenLabs API Key**](https://elevenlabs.io/app/settings/api-keys) を取得します。
2. アプリの「設定」→「API Key」で取得した [**API Key**](https://elevenlabs.io/app/settings/api-keys) を入力し、「確認して有効化」をタップします。

これでElevenLabsの音声を利用できます。


## ElevenLabs API Key 生成

① 以下のページを開き、ログインします。Googleアカウントを使うと簡単です。
https://elevenlabs.io/app/settings/api-keys

② スクリーンショットの3つの手順に沿って、APIキーを取得します。

- アプリ名は自由に設定して構いません。
- 現在の無料枠は10,000クレジットなので、ここでは利用上限を9,000に設定しています。
- 「テキスト読み上げ」の権限を忘れずに有効にしてください。
