# Revia — 原生 iOS

使用 SwiftUI + 系统 SQLite 构建的 Revia，使用 RxSwift / RxRelay 管理语音功能的异步状态；不需要 Node.js、Expo、CocoaPods 或开发服务器。iOS 17+，推荐 Xcode 26.3+。

## 运行

打开 `Revia.xcodeproj`，选择 Revia target，在 Signing & Capabilities 中选择自己的 Team。默认 Bundle Identifier 是 `com.jeffkann.revia.native`，可按需要修改。连接 iPhone 并启用开发者模式，选择手机后点击 Run。Debug / Release 都可以离线运行；SwiftUI 和业务代码均可在 Xcode 中打断点。

## 功能

- 三个 Tab：日历、今天、设置；今天页面返回前台或日期切换时更新。
- 点击日期进入当天内容；新增绿色背景、复习灰色背景，不显示类型标签。日历保留绿色新增点和灰色复习点。
- 支持任意语言的句子原文、可选释义和学习日期，允许补录、同日多句。
- 15 次固定复习：第 1、3、7、14、30 天；以第 5 次日期为锚点，随后每个日历月一次，共 10 次。月份没有对应日号时取月末，不改变后续月份的锚点日号。
- 没有完成状态、打卡或动态延期。从任意卡片删除会删除原句及全部复习日程。
- 数据保存在应用沙盒 Application Support/revia.db，退出/重启保留。没有云同步和导入导出。Expo Go、React Native App 和原生 App 的沙盒独立，句子不会自动迁移。卸载 App 会删除本地数据。

在 Xcode 中按 Command-U 执行单元测试（选择已安装的模拟器或已配置签名的手机）。工程已包含共享 Scheme。

## ElevenLabs 语音

第三个 Tab「设置」中输入 ElevenLabs API Key，点击「验证并激活」。Key 安全保存在本机 Keychain（WhenUnlockedThisDeviceOnly），不写入 SQLite 或日志。修改/移除 Key 会立即停用生成；重新验证后恢复。验证仅要求 Text to Speech 权限，使用所选音色（默认 George）合成短句 `Hi.`，会消耗少量额度，不自动播放或保存试音。随后尝试分页 `/v2/voices` 获取音色，列表读取失败不阻止已通过 TTS 验证的 Key 激活。仅 TTS 权限时可使用默认音色或手动填写 Voice ID（填写后点击「使用此音色」）；验证失败时可检查音色访问权限与账户额度。HTTP 401 的 `missing_permissions` 会显示权限错误，而非误判 Key 无效。

可从账户可用音色中选择，默认使用 George。模型为 `eleven_v3`，输出 `mp3_44100_128`。请求使用 HTTPS 和 `xi-api-key`；仅在保存勾选生成或播放本地缺失的语音时，将句子原文发送给 ElevenLabs。释义不发送。

激活 Key 且有可用音色时，添加页的「生成语音」默认勾选，可取消；未激活时禁用且不选中。句子先保存，生成失败弹窗提示，退出后可点击播放重试，不会重复添加句子。

音频位于 Application Support/Speech。SQLite 的 `audio_records` 保存句子、文本、文件名、音色、模型、版本和创建时间；文本/音色/模型/版本参与缓存键。播放优先读取当前音色缓存，文件缺失才生成。没有可用 Key 时仍可播放此句已有录音。切换音色后旧版本保留，文件实际总大小显示在设置页。删除句子会关联删除元数据并清理文件（相同文本共享的音频仅在最后一个引用删除时移除）。启动时清理中断操作留下的无引用 MP3。

RxSwift / RxRelay 6.10.2 通过 Swift Package Manager 引入，用于激活条件组合、验证和合成请求的异步链及取消。首次打开工程需要联网解析 Swift Package，之后 App 运行不依赖开发服务器。

测试包括日期/持久化、音频元数据和关联删除、缓存路径/占用、模拟 HTTP 验证/音色分页/错误响应；未包含真实 API Key，真实合成与扬声器播放需要在手机上配置 Key 后验证。

## 界面语言

设置 Tab 顶部可选择 English、中文（简体）或日本語，立即生效并保存在 UserDefaults，无需重启，也不会重建导航/清空表单/停止播放。首次启动选择设备首个支持的语言，其他语言回退为英文。

`Features/Localization/Localization.swift` 管理语言偏好与格式化，`Resources/Localization/` 下的 `en.lproj`、`zh-Hans.lproj`、`ja.lproj` 中的 `Localizable.strings` 包含三语文案。日期、星期、数量、存储容量以及应用自己的错误提示均按所选语言显示。学习日期仍按本地公历存储，复习规则不随界面语言变化。

界面采用“句子”“释义”“生成语音”等中性文案。界面语言不会翻译学习内容，也不会改变/重新生成已有音频。Swift 模型和接口统一使用 `text`；SQLite 仅保留旧 `japanese` 列名以兼容已有数据，实际可保存任意语言的句子；ElevenLabs Eleven v3 根据原文生成语音。

验证：iOS Debug 与测试目标编译通过，12 项核心回归测试通过；所有三语资源键及格式占位符一致性检查通过。仍需在手机上检查三种语言的实际布局与即时切换交互。

本地化 key 统一使用简短英文 snake_case（如 `save_sentence`、`audio_storage`），不使用中文或完整句子作 key。三种语言使用同一组 key，格式占位符保留在翻译值中。新增文案时需同时补齐三语资源。


## JSON 换机备份

设置 → 数据备份 → 导出 JSON，使用 iOS 系统分享菜单通过 AirDrop、消息或“存储到文件”保存。另一台手机在设置中选择导入 JSON。格式标记为 `revia`，版本为 `1`；每条记录包含 `text`、`translation`、`learningDate`、`createdAt` 和完整的 15 个 `reviewDates`，不包含音频、API Key 或本地记录 ID。

导入一次性追加所有句子，不去重、不覆盖；重复导入会产生重复记录。学习日期和复习日期按日历日期原样保留，添加时间使用 UTC 时间戳。导入不会重新计算计划，重启后也不会补算或修改导入日期。无效备份整批拒绝；数据库事务确保写入失败时不留下部分内容。

## 每日学习提醒

设置 → 每日学习提醒中开启通知并选择时间，默认时刻为手机当地时间 19:00，初始开关关闭。仅在主动开启时请求通知与声音权限；权限被拒绝时可从页面进入系统通知设置。使用 `UNCalendarNotificationTrigger` 的每日重复条件，仅保存一条固定标识的本地通知。修改时间替换原通知，关闭开关取消通知，App 回到前台时同步系统权限和当前界面语言。不使用 APNs、远程服务器或 Push Notifications entitlement，离线、App 未运行时也可由系统提醒。显示和声音受系统通知设置、专注模式及通知摘要影响。

提醒开关和时间保存在本机偏好设置中，不包含在句子换机备份中。通知权限弹窗、实际送达时间和声音需在真机验证。

## 重置复习计划

句子卡片的播放按钮只显示图标，右侧的刷新图标用于重置复习计划。确认后以点击当天为新起点，重新生成固定 15 次复习日期。原句的学习日、添加时间、释义与音频不修改。所有原始复习日期都保留在数据库：旧周期截至重置当天的日期继续显示，旧周期之后的未来日期停用；新周期从当天开始显示。若重置日也是原学习日，当天只显示一张新增卡片。同一天反复重置不会叠加周期。

数据库以 `review_cycles` 和 `cycle_reviews` 追加保存重置周期，不覆盖原 `reviews` 日期。导出包含重置记录时使用备份版本 2，并携带 `resetCycles`（每轮的 `startedOn`、`createdAt`、`reviewDates`）；无重置记录时继续使用版本 1。新版本可以导入两种格式，含重置记录的备份需用新版 App 导入。

## 自定义学习计划

设置 → 学习计划可以创建有名称的自定义计划。当前最多3个，包含1个不可删除的标准计划和2个自定义计划。天数方块为1、2、3、4、5、6、7、15、30；天数累计，点击「安排复习」放置一个复习节点。例如1 → 复习 → 2 → 复习代表学习后第1、3天。每个计划至少1个、最多15个复习节点，无需凑满15个，最后须以复习节点结束。

新增句子时选择计划，句子保存该计划的独立快照。以后修改或删除模板不会改变已有句子；刷新复习时沿用该句子的计划。默认计划仍为1、3、7、14、30天后，再按日历月安排10次。自定义计划的节点均为累计天数，不自动补充月度节点。

模板保存在本机偏好设置中。句子的计划快照通过 `sentence_plans` 表持久化，包含自定义计划的句子备份使用版本3（兼容读入版本1和2），携带 `studyPlan` 名称及间隔，导入后仍能正确保留和重置计划。
