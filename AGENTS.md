# Revia iOS project conventions

This repository is the native SwiftUI iOS application, separate from the Expo project in the sibling Revia directory.

## Documentation

- Reserve the root README.md for user-facing app presentation. Keep it empty until the user requests presentation content; do not add architecture, setup instructions, change logs, or test reports there.
- Put developer and architecture documentation in the root app-architecture/ directory.
- Use English directory and file names. Maintain matching Chinese and Japanese documents, starting with Architecture.zh-CN.md and Architecture.ja.md.
- When technical behavior changes, update both language versions rather than appending notes to README.md.
- Keep icon and launch asset documentation in AppIcon.zh-CN.md and AppIcon.ja.md in the same directory.

## Commits

- Write commit messages in Japanese.
- Commit and push only when requested by the user.
