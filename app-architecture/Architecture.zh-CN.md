# Revia 应用架构与开发说明

本文件面向开发与维护。根目录 `README.md` 保留给 App 展示，不放技术说明；当前按要求保持为空。后续技术说明统一放在 `app-architecture/`，文件名使用英语，并同步维护中文和日文版本。

[日本語版](Architecture.ja.md) · [图标说明](AppIcon.zh-CN.md)

## 技术与运行

- 原生 SwiftUI 应用，最低 iOS 17；使用系统 SQLite、Keychain、AVFoundation 和 UserNotifications。
- RxSwift / RxRelay 6.10.2 通过 Swift Package Manager 管理，用于语音请求、取消与激活条件组合。
- 不需要 Expo、Node.js、CocoaPods 或开发服务器。与旧 Expo 项目使用独立沙盒，不自动迁移数据。
- 推荐 Xcode 26.3 或更新的兼容版本。打开 `Revia.xcodeproj`，选择 Revia target，在 Signing & Capabilities 中选择自己的 Team，按需要调整 Bundle Identifier。
- 真机需启用开发者模式并配置签名，然后选择设备运行。Debug 与 Release 都不依赖开发服务器；本地内容可离线使用，生成新语音需要网络。

## 页面与交互

四个 Tab：日历、今日、全部句子、设置。日历按月展示，点击日期进入当天内容；今日页随日期切换和返回前台刷新。已移除九个月总览和双指缩放。

日历的新增绿点只在学习日期等于今天时为绿色，过往日期变灰。句子卡片的绿色背景也仅对当天新增有效，复习卡片为灰色；深色模式使用对应的墨绿和深灰绿配色。不提供“已复习”或完成打卡状态。

全部句子支持搜索原文和释义，按实际添加时间从新到旧排序；卡片不额外展示添加时间。日期显示不包含时分秒，底层时间戳仍保留。学习日期只读，由添加入口对应的日期决定，允许从日历向其他日期添加。

共享卡片提供播放/停止图标、刷新复习图标、右上角删除“×”和可折叠备注。默认是否折叠备注由设置控制。删除会移除句子、全部复习周期和相关音频元数据，并按文件引用情况清理音频。

设置首页保留语言、外观、备注折叠、学习计划、每日提醒、声音类型、API Key 状态、导入导出入口和语音存储占用。Key、备份、提醒、计划编辑使用二级页面。手动音色 ID、完整音色列表和模型信息目前不在设置界面展示。

## 固定复习与自定义计划

默认计划共 15 次：学习日期后第 1、3、7、14、30 天，再以第 5 次日期为锚点，每隔一个日历月安排一次，共 10 次。月份不存在对应日号时取月末，后续月份仍以原锚点日号计算。

计划总数最多 3 个：1 个默认计划与 2 个自定义计划。自定义计划可以命名，使用 1、2、3、4、5、6、7、15、30 天的方块累计间隔，再放置“安排复习”节点。例如 `1 → 复习 → 2 → 复习` 得到学习后的第 1、3 天。节点是预定复习日期，不代表实际完成打卡。

自定义计划需要 1～15 个节点，节点之间至少相隔一天，最后以节点结束；不自动补充至 15 次，也不自动追加月度复习。新增句子时可选择计划，每条句子保存独立快照。之后修改或删除模板不影响已有句子。

模板使用 UserDefaults 的 `study.plans` 保存；句子的计划快照位于 SQLite `sentence_plans`。模板目录本身不随句子备份恢复，但备份中的句子会保留自己的规则和名称。

## 刷新复习

点击刷新立即以当天为起点，沿用该句子保存的计划，成功后弹窗说明。默认句子沿用默认规则，自定义句子沿用其快照。

原学习日期、添加时间、文本、释义和音频不改动。旧周期中截至重置当天的日期继续显示，之后的未来日期停用，但原始记录不删除。新周期从当天开始；同一天重复刷新不叠加周期。若刷新日就是原学习日，当天不重复展示一张复习卡片。

`review_cycles` 和 `cycle_reviews` 追加保存刷新周期，`reviews` 保留最初计划。有效日程查询合并历史与当前周期，去除旧周期已停用的未来日期。重启不能重新计算或补回已停用计划。

## 本地数据

- 主数据库：Application Support/revia.db，启用外键和 WAL。
- 语音目录：Application Support/Speech。
- 主要表：`sentences`、`reviews`、`sentence_plans`、`review_cycles`、`cycle_reviews`、`audio_records`。
- 当前 schema 版本为 5。旧 schema 小于 3 时才执行历史复习日补齐；之后保留已有实际日期，避免破坏导入和重置计划。
- 旧 SQLite 列名 `japanese` 为兼容而保留，实际保存任意语言句子；Swift 模型和接口统一使用 `text`。
- 语言、外观、备注折叠、提醒、计划模板及音色偏好使用 UserDefaults。API Key 只存 Keychain。
- 目前没有云同步。卸载应用会删除本地沙盒数据。

## ElevenLabs 语音与缓存

模型为 `eleven_v3`，输出为 `mp3_44100_128`。男声 George：`JBFqnCBsd6RMkjVDRZzb`；女声 Sarah：`EXAVITQu4vr4xnSDxMaL`。账户和 Key 仍须允许使用所选音色。

Key 使用 Keychain 的 WhenUnlockedThisDeviceOnly 保存，不写入 SQLite、备份或日志。编辑或移除 Key 会停用生成。验证使用所选音色合成短句 `Hi.`，会消耗少量额度，不自动播放或保存试音。只要求 Text to Speech 权限；音色列表读取属于可选步骤，读取失败不阻止已通过 TTS 验证的 Key 激活。`missing_permissions` 与无效凭证区分提示。

有激活的 Key 和可用音色时，添加页默认勾选生成语音，可取消。句子先保存，语音失败弹窗提示，之后可播放重试，不重复添加句子。只发送句子原文，不发送释义。

播放优先读取该句已有本地录音，缺失时才生成。切换音色只影响新生成的语音，不强制重建已有录音。无 Key 时已有本地录音仍可播放。

文件名不是 MD5，而是 `SHA-256(缓存版本 + NUL + 音色 + NUL + 模型 + NUL + 原文) + .mp3`。日期和释义不参与缓存键。相同原文、音色、模型与版本可以共享文件；标点和空格也参与哈希。只有最后一个引用被删除后才清理共享文件。启动时清理无引用 MP3，保存前验证音频能否解码。

## 换机备份

设置 → 导入与导出。导出通过系统分享，可用于 AirDrop、消息或存储到“文件”；导入使用系统文件选择器。界面不展示 JSON 等实现术语。

备份只含句子与计划，不含音频、API Key、本地自增 ID 或应用设置。每条记录包含 `text`、`translation`、`learningDate`、`createdAt`、实际 `reviewDates`，按需加入 `resetCycles` 和 `studyPlan`。

- 版本 1：无自定义计划或重置周期的基本句子。
- 版本 2：包含重置周期。
- 版本 3：包含自定义计划快照；也可同时包含重置周期。

当前应用读取版本 1～3。导入一次性追加，不去重、不覆盖，重复导入会重复添加。学习日和复习日使用 `YYYY-MM-DD`，添加与重置时间使用 UTC 时间戳；实际复习日期原样恢复，不重新计算。备份先整批校验，再在事务中写入，失败不留下部分数据。

## 本地通知

设置 → 每日学习提醒，默认时间为当地 19:00，开关初始关闭。仅主动开启时申请提醒和声音权限；拒绝后提供系统通知设置入口。使用一条固定标识的每日重复 `UNCalendarNotificationTrigger`，修改时间替换原通知，关闭时取消。

不使用 APNs、远程服务器或远程推送 entitlement。系统可以在离线或 App 未运行时提醒。显示和声音受系统通知设置、专注模式和通知摘要影响。返回前台时同步权限并更新当前语言的通知内容。

## 语言、外观与启动

支持英文、简体中文和日文，首次按设备语言选择，其他语言回退英文。切换立即生效，不重启，不翻译句子、不修改复习计划。字符串 key 使用简短英语 snake_case，新增和修改文案需同步三种语言与格式占位符。

外观支持跟随系统（默认）、浅色、深色，立即生效并保存。`Shared/Palette.swift` 提供语义动态颜色；新增页面要复用配色，避免固定白色输入框或深色模式下对比不足。

系统 Launch Screen 静态显示深色脑图标与 Revia。App 内启动动画沿三个节点按 1→2→3→1 发光，一轮 1.6 秒，以先快后慢方式减速，然后淡出。开启系统“减弱动态效果”时跳过光流。日历加号使用系统缩放转场展开新增页；旧系统或减弱动态效果下使用普通呈现。

## 验证与维护

- 在 Xcode 选择支持的模拟器或配置好签名的真机，按 Command-U 运行测试。
- 可用 `xcodebuild -project Revia.xcodeproj -scheme Revia -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build-for-testing` 检查设备目标与测试目标编译；这不等于已经运行真机测试。
- 日期、月末、SQLite、缓存、备份版本、重置周期、计划节点/上限、本地化、模拟 HTTP 和提醒调度均有测试覆盖。
- 真实 TTS、扬声器播放、权限弹窗、本地通知送达、动画手感与三语布局需在设备检查。不要在文档里将模拟测试写成真实 API 验证。
- 修改数据结构时保留旧数据，检查重启、备份恢复、删除级联与计划快照。修改复习规则不应重算已有句子。
- Commit 信息使用日语；提交或推送按用户当次授权执行。
